## Game engine

Develop Tequila Kill in `godot/`. Read the root README.md for the engine
version, setup and verification commands. Before implementing gameplay
or inputs, read [the concept and decision links](docs/concept.md).
Networking comes later.
Apply Game Studio skills only where they fit the Godot workflow.
